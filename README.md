
# Government Post Graduate college Mardan — Student Record Management System

A responsive student record management application built with React, JavaScript,
CSS, and Vite. It supports creating, viewing, searching, filtering, editing, and
deleting student records. Records are kept in the browser using localStorage.

## Features

- Controlled student registration form
- Create, read, update, and delete student records
- Unique student IDs
- Required-field and email validation
- Search by student name, email, or ID
- Filter by department
- Statistics for total students, departments, and displayed records
- Confirmation before deletion
- Feedback messages and empty states
- Responsive layout and semantic form controls
- Browser localStorage persistence

## Requirements

- Node.js LTS
- npm

```bash
npm install
npm run dev
